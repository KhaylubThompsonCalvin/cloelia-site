# cloelia-site

The public site of **CLOELIA.AI**: a reference that measures how people's practical freedoms
changed. For one freedom at a time, in one place at a time, a Record shows what happened, what
followed, for whom, what can be measured, how strong the evidence is, and what remains unknown.
Descriptor: Freedom Analytics. Tagline: Freedom, measured.

Static Astro site. No number on it is typed by hand: measures, charts, datasets, and findings arrive
from the laboratory repository (`cloelia-investigations`) through a one-way bridge that validates
each investigation's `publish/` folder against the artifact contract and records the lab commit.

## Run

```
npm ci
npm run bridge -- --fixture   # or: npm run bridge  (reads ../cloelia-investigations, or LAB_DIR)
npm run check                 # types and content schemas
npm run validate              # relationships, the standard's required fields, banned characters
npm run build                 # production build (npm run build:preview for the noindex staging build)
npm run validate              # again, against dist/
npm run test:unit             # the bridge against the lab fixtures
npm test                      # Playwright: structure, Record order, grades, verify layer, JS off, axe, keyboard, headers, feeds
npm run lhci                  # Lighthouse budgets on every template
```

`node .claude/hooks/verify-guard.mjs full` runs the whole list and writes the verification stamp.

## Content

Editorial content (what happened, in the source's own terms) is YAML under `src/content/`. Computed
content (what followed) is JSON under `src/content/bridge/`, generated by `scripts/bridge.mjs` and
committed. Schemas: `src/content.config.ts`. Cross-entity rules: `scripts/validate.mjs`.

## Deployment

`render.yaml` declares the staging service (preview build, noindex, pull-request previews). The
production service and the domain are added at Phase 6 of the roadmap.

## Standard

Five evidence grades (Measured, Documented, Inferred, Contested, Insufficient evidence); provenance
for every number and event; for whom, always; no scoring of actors; no composite index; no
prescriptions; disagreement shown, not resolved; corrections public. The full standard and the
product definition live in the owner's vault.
